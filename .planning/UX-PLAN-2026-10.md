## TL;DR

1. **Three onboarding bugs break the first-run story.** Creating a game in
   the wizard ejects the coach to game detail (step 5 never happens); the
   "Basics" step pill links to `/teams/new` and creates a second team; the
   scoring step says "Default for Under 14: on" while the team is created
   with scoring off.
2. **Team settings shows "0 members" for every team** — the members query
   is an ambiguous PostgREST embed (PGRST201). Admins can't see or change
   roles. Verify in prod; nothing in e2e covers it.
3. **Game day takes 5 taps across 4 screens before the clock runs**, and
   the first thing a new coach sees after "Start Q1" is a modal walkthrough
   sitting over the running clock.
4. **One lineup, three pictures.** AFL — the reference sport — shows zone
   *lists* pre-game, a *field* in play and *lists with bars* at the break;
   rugby league shows a *field* pre-game. The coach re-learns the layout at
   every stage.
5. **The engine can't hear the coach.** "Player chips → Linked to
   positions" silently act as near-fixed lines (at the Q2 break, 12 of the
   13 kids who stayed on kept their line), while locks live in browser
   storage and vanish.
   There's no way to say *home position*, *preferred*, *never here*, or
   *minimum time*. Workstream 2 (Playbook) fixes this per sport: the sport
   defines its positions and rotation strategies, the age group sets the
   policy (zones, game-time floor) with league overrides, and the coach
   picks a strategy, roles and rules. Named positions only appear for AFL
   once zones stop (U11+ by default); netball keeps its fixed bibs and
   chooses *how* to rotate (by thirds, position by position, position
   cycle…). A core **season balance** rule evens out each kid's time in
   each position, line or third across the season. It absorbs chips, the
   sport-specific toggles and the per-session rotation mode.

## 1. Design principles

These are the tests every roadmap item below is checked against.

1. **Sideline first.** One hand, three seconds, sun on the screen. Nothing
   modal appears while the clock runs unless the coach asked for it. Every
   game-day target is ≥ 44 pt.
2. **One lineup, one picture.** The same field/court diagram — same slot
   positions, same tile — is used pre-game, live, at the break, in the
   game plan and in the positions editor.
3. **Your team, your rules.** The age group sets safe defaults; the coach's
   Playbook overrides them; the engine says *why* it suggested something.
4. **Complexity arrives by age, not by accident.** An U8 Auskick coach
   never sees positions, rules or vest plans unless they go looking. A U16
   coach gets them in setup.
5. **One name per thing.** A single glossary (§5) across UI, Help and
   marketing.
6. **Every screen has one obvious next step.** One primary button per
   screen/state; everything else is secondary or in an overflow menu.
7. **Differences live in data, not chrome.** AFL is the reference; netball
   and league differ through sport config (`src/lib/sports/*`), not forked
   components (per `CLAUDE.md`).

## 4. Journeys

### New coach — signup to first whistle

```
Landing ─ Start free ─▶ /login (email) ─▶ inbox ─▶ /welcome ─▶ Set up a new team
  ─▶ 1 Basics (sport, name, age)        ✓ clear
  ─▶ 2 How we play (scoring, chips)     ✗ C4 default lie; chips jargon
  ─▶ 3 Squad (one kid at a time)        ✗ M3 ~3 fields × 18 kids
  ─▶ 4 Games (PlayHQ / manual)          ✗ C2 ejects to game detail
  ─▶ 5 All set (never reached)          ✗ invite + availability lost
  ─▶ Team home (one card)
```

**Target:** Basics → *How you coach* (age policy + strategy, scoring default from
age) → Squad (paste list) → Fixture → Invite → **Today** with the first
game ready. Wizard in its own focused shell; every step returns to the
wizard.

### Returning coach — game day

```
Today (tap 1: Open game) ─▶ Game detail (tap 2: Start game) ─▶ Availability
(tap 3: Continue to lineup) ─▶ Lineup (tap 4: Ready for Q1) ─▶ Modal
(tap 5: Start Q1) ─▶ Walkthrough modal (tap 6: Skip)
```

**Target — 3 taps:** Today hero "Start game day" → Game-day screen
(availability inline as a "Not here today" strip under the bench; lineup on
the field diagram; rule check bar) → **Start Q1** (one confirm: "Start when
the siren goes"). The walkthrough is offered on the lineup screen *before*
kickoff, never after.

### Quarter break

Works well (STAYS / BENCH → FORWARD labels, minutes visible, Suggested /
Rotate lines / Keep last / Set manually). Problems: list layout ≠ field
(H4); rotation mode is chosen every break although it's really a coaching
strategy (→ Playbook default); netball lacks "Rotate lines" with no
explanation.

### Full time

Full time → Finalise → summary with "Copy for group chat" (AFL, netball) is
strong. RL has no summary. A final game's detail page leads with "Open live
game" (H3).

### Parent / runner

Runner link (`/run/[token]`) was fixed after the May tests (orientation
banner, enforced minimum). Parents who join with the team code land in the
coach's tab set, including Settings. There is no designed parent product
yet — see open questions.

## 7. Workstream 2 — Playbook: tailor Siren to how each coach works

**Steve's steer (12 Oct):** positions only come into play once an age
group stops forcing zones (AFL, around U11–U12). In netball the positions
never change; what changes is *how you rotate* — by thirds as groups, or
each position independently. Rules must work according to each sport.

**Steve's decisions (12 Oct):** minimum game time defaults to 50 % and
stays editable for leagues that require more; zones end at U10; every
netball rotation style is in scope; and rotations should aim to even out
each player's time in each position across the whole season, where that's
the coach's preference (§7.5).

So the design has three layers, and only the last one belongs to the coach:

| Layer | Who sets it | What it holds |
|---|---|---|
| **Sport model** | Code, per sport | Lines, the position set, whether positions can be renamed or added, which rotation strategies and rules exist |
| **Age policy** | Code defaults per age group; the coach can override where leagues differ, unless a rule is locked | Zones enforced?, minimum game-time band, vest rules, unbroken periods, scoring default |
| **Coach's Playbook** | The coach, per team | Chosen strategy, positions (where the sport allows), player roles, rule settings within the policy bounds |

### 7.2 What the policies actually say

- **AFL** — national junior rules (May 2024 handbook, play.afl). Zone
  splits are listed only for **U8** (2-2-2 at 6-a-side), **U9** (3-3-3) and
  **U10** (4-4-4). Every age group, U8 to U18, carries the same player
  rotation rule: *every player must play a minimum of 50–75 % game time,
  with the controlling body determining the exact %*. The codebase already
  treats U8–U10 as rotation-mandated (Steve corrected it from U11 on
  2026-05-20). **Decided:** zones for U8–U10, named positions from U11, with the
  per-team override kept because leagues vary. The game-time floor
  defaults to 50 % and setup lets the coach raise it to the league's figure.
- **Netball** — the NetSetGO modified-rules fact sheet (Aug 2026) sets no
  national rule forcing rotation through positions. It suggests rotating
  players into unfamiliar positions in one-sided games. NSW carnival rules
  ask that players experience all positions across the day. Associations
  can add stricter local rules.
- **Rugby league** — NRL Modified Games (Mini Footy U6–U9, Mod League
  U10–U12). The policy that matters to Siren is vests (First Receiver,
  Dummy Half) and unbroken periods, both already in the age config. No
  national position-rotation rule was found.

### 7.3 Per-sport models

| | **AFL — zoned ages** (default U8–U10) | **AFL — open ages** (default U11+) | **Netball** | **Rugby league** |
|---|---|---|---|---|
| Lines | Back · Centre · Forward, with zone splits | Back · Centre · Forward | Attack · Centre · Defence thirds | Forwards · Backs (`forwardCount` per age) |
| Positions | None — zone slots only | Named, coach-defined, defaults by on-field size | Fixed bibs (5 at Set: GS GA C GD GK; 7 from Go) | Optional fixed catalogue from Mod League: FB, WG, CE, 5/8, HB, PR, HK, 2R, LK |
| Coach can rename / add? | — | **Yes** (≤ 4-char labels, add/remove within on-field size) | **No** | Pick from the catalogue, no renaming |
| Duties | — | — | — | FR / DH vests (rotating duties, not positions) |
| Strategies | Suggested · Rotate lines · Keep last quarter · Manual | Free rotation · Preferred lines · Set positions | By thirds · Position by position · Position cycle · Partners · Set positions | Both lines · Preferred line · Named positions (U10+) — plus a vest strategy |
| Locked by default | Rotate through every zone; game-time floor | Game-time floor (default 50 %, editable to 75 %) | Nothing nationally; association rules optional | Vest rules; unbroken periods by age |

**Switching zones off** (e.g. "our league doesn't zone U10") moves the
team to the open-age model and reveals the positions step. Switching them
on for U11+ does the reverse and hides positions. Both are one toggle on
the policy card, with a line saying what changes.

#### AFL open-age strategies

| Strategy | What it does | Typical fit |
|---|---|---|
| **Free rotation** | Equal time, every line across the game, no positions shown | U11 coaches not ready for positions |
| **Preferred lines** | Kids lean to one or two lines but still get a stint elsewhere | U11–U12 |
| **Set positions** | Named positions, home + also-plays, like-for-like bench, game-time floor | U13+ |

Default AFL positions (editable starting points; lines map 1:1 onto today's
zones so zone stats and fairness bars keep working; two slots may share a
label):

| On field | Back line | Centre line | Forward line |
|---|---|---|---|
| **18** | BP · FB · BP · HBF · CHB · HBF | W · C · W · R · RR · ROV | HFF · CHF · HFF · FP · FF · FP |
| **16** | BP · FB · BP · HBF · CHB · HBF | C · R · RR · ROV | HFF · CHF · HFF · FP · FF · FP |
| **15** | BP · FB · BP · CHB · HBF | W · C · R · RR · ROV | HFF · CHF · FP · FF · FP |
| **12** | BP · FB · BP · CHB | W · C · R · RR | FP · FF · FP · CHF |

#### Netball rotation strategies

| Strategy | How a quarter is built | Typical fit |
|---|---|---|
| **By thirds** | Kids move as a third: a whole quarter in attack, centre or defence, rotated through thirds across the game; the bib within a third is chosen for fairness | Go and 11U development — this is today's engine behaviour, made explicit |
| **Position by position** | Each bib is filled on its own; the target is the most different bibs per kid across the game and season | Coaches who want every kid to wear all 7 bibs |
| **Position cycle** | A fixed order (GS → GA → WA → C → WD → GD → GK → bench); everyone steps one along each quarter | Set and Go; easy for parents to follow. Netball's answer to AFL "Rotate lines" |
| **Partners** | Kids keep their third but swap with their partner each quarter (GS↔GA, GD↔GK, WA/C/WD) | 12U–13U, starting to specialise |
| **Set positions** | Home bib + backups; bench rotates like-for-like | 13U and Open |

#### Rugby league strategies

| Strategy | What it does |
|---|---|
| **Both lines** | Every kid plays forwards and backs across the season (uses today's forward/back time bars) |
| **Preferred line** | Kids lean to forwards or backs (replaces chip a/b) |
| **Named positions** (U10+) | Kids get home positions from the catalogue; formation slots already exist in `fieldFormation.ts` |
| Vest strategy | **Auto-fair** (today) · **Fixed order** (roster rotation) · **Coach picks** each half — always within the vest rules |

**Season balance (§7.5) is on by default for every strategy except Set
positions.** Preferred-line strategies balance against the player's target
split rather than an even one.

### 7.5 Season balance — a core rule

**The rule:** *Even out each player's time in each [position] across the
season.* It's a Playbook rule (Prefer) with a strength — **Light /
Balanced / Strong** — that sets how much the season counts against today's
game. It's on by default for every rotating strategy, off for Set positions
(home positions are the point), and for preferred-line strategies it
balances against the player's target split instead of an even one.

**What gets balanced, by sport and strategy:**

| Sport · strategy | Unit balanced over the season |
|---|---|
| AFL zoned ages (any strategy) | Zone (back / centre / forward) |
| AFL open · Free rotation | Line |
| AFL open · Preferred lines | Line, against the target split (e.g. 60 % preferred line, rest shared) |
| AFL open · Set positions | Off |
| Netball · By thirds | Third |
| Netball · Position by position, Position cycle | Bib (GS … GK) |
| Netball · Partners | Bib, within the player's third |
| Netball · Set positions | Off |
| RL · Both lines | Line (forwards / backs) |
| RL · Preferred line | Line, against the target split |
| RL · Named positions | Position |
| RL vests | Already balanced by season vest counts — unchanged, shown alongside |

**The maths (one formula, every sport).** For player *p* and unit *u*:

- target share *t(p,u)*: even across the units *p* is allowed to play
  (*never* rules removed), or the preferred split;
- *owed(p,u) = t(p,u) × seasonOnField(p) − seasonTime(p,u)*, converted to
  **periods owed** (÷ this game's period length) and capped at ±2;
- score term = *W_season × owed(p,u)*.

Who plays is still decided by this game's minutes (equal time) and the
time floor. Season balance only decides *where* kids play. At zoned ages,
within-game variety ("every zone this game") stays ahead of it because the
policy requires it.

**Weights per engine (starting points, tuned with Vitest fixtures):**

| Engine | Today | Proposed |
|---|---|---|
| AFL `suggestStartingLineup` | Binary `SEASON_DIVERSITY` +500 when a kid has under one full quarter in that zone all season, plus a small minutes term (`fairness.ts:623-659`). Swamped by in-game variety (+1000) and chips (+5000). | Replace both with *W_season × owed*: Light 150 · **Balanced 300** · Strong 600 per period owed (cap ±2). Balanced tops out at 600: below in-game variety (1000), so "every zone this game" still wins at zoned ages, but enough to beat same-as-last-quarter (−800) when a kid is two quarters short. Strong can outweigh in-game variety at open ages. |
| AFL `suggestSwaps` | Prefers a zone the incoming kid hasn't played this game | Tie-break on *owed(p,u)* so rolling subs also pay down season debt |
| Netball `suggestNetballLineup` | `seasonRarity = −seasonCount` (quarters at that bib), a single-digit tiebreak under tiers worth 10,000–350,000 (`netball/fairness.ts:615`) | A real tier: Light 10,000 · **Balanced 20,000** · Strong 40,000 per period owed (cap ±2). It sits below "unplayed third this game" (+100,000) and the same-bib-this-game penalty (−50,000), and above same-third-as-last-quarter (−10,000). Unit = third or bib by strategy. For *Position cycle*, season balance picks each kid's starting bib for the game, then the cycle runs. |
| RL `suggestLeagueLineup` / `suggestLeagueSubs` | Season balance covers total playtime ratio and vest counts only; forwards/backs fixed by chip | After the who-plays ranking, line (or named position) is chosen by *owed(p,u)*; vest logic unchanged |

**Where season time comes from:**

- **Today: derived on every read.** `getSeasonEvents` (`src/lib/season.ts`)
  pulls every `game_event` for the team (cached 300 s, invalidated on
  write). Then `seasonZoneMinutes` (AFL, ms per zone, `fairness.ts:468`),
  `seasonPositionCounts` (netball, quarters per bib,
  `netball/fairness.ts:246`) and RL's `seasonVestCountsByPlayer` / playtime
  walk each one again. The comment in `season.ts` already flags about 2,000
  rows per render for a 10-game team.
- **v1, no migration:** one shared `seasonTimeByUnit(events, unitOf)`
  that walks `lineup_set`, `swap`, `period_break_swap`,
  `league_position_change`, `injury`, `player_loan` and `quarter_end` into
  **ms per player per unit**, for any unit (zone, line, third, bib,
  position). Netball moves from quarter counts to minutes, which it needs
  once mid-quarter subs are on. Same cache as today.
- **v2, with named positions:** a `player_season_time` rollup
  (team_id, season, player_id, unit_kind, unit_key, ms, periods).
  - It's written when a game is finalised and rebuilt when a final game is
    restarted or edited.
  - Live and break screens read the rollup for finished games and add the
    current game from memory.
  - A Vitest asserts rollup == derived on fixture seasons; a backfill
    script fills past games.
  - Unit keys come from `games.playbook_snapshot`, so renaming a position
    later never rewrites history.

**How coaches see it:**

- **Quarter break and game day.** The rule check lists the biggest season
  gaps among kids in this lineup: "Mia hasn't played defence this season",
  "Jack is 2 quarters short at CHB". The Why chip names it when it drove a
  suggestion ("Mia → GD: owed defence time this season"). If the coach
  overrides, the nudge stays as a soft warning and never blocks.
- **Player view** (role sheet, player insight). "This season" bars per
  unit against the target, with "owed" called out.
- **Stats.** A **Season balance** grid (players × units, shaded by gap from
  target, sortable by biggest gap) replaces "Minutes equity". One
  plain-language line per team: "9 of 12 kids within a quarter of even".
- **Lineup picker.** The existing "Season time in zone" line under each
  AFL player, generalised to every sport and unit.
- **Summary.** A "Season balance: improved for 8 kids" line next to
  "Rules kept".


### 7.6 Shared framework

One shape for all three sports. Sport files supply data; the engine and UI
read the same config.

```ts
// src/lib/playbook/types.ts
type Overridable<T> = { default: T; overridable: boolean; source?: string };

interface AgePolicy {
  zonesEnforced: Overridable<boolean>;          // AFL: true U8–U10 by default
  minGameTimePct: Overridable<number> & { band?: [number, number] }; // AFL 50–75
  lockedRules: RuleRef[];                        // shown, not editable
  vests?: VestPolicy;                            // RL
  minUnbrokenPeriods?: Overridable<number>;      // RL
  tracksScoreDefault: boolean;
}

interface PositionModel {
  kind: "none" | "fixed" | "catalogue" | "custom";
  lines: LineDef[];                              // id, label, colour token
  defaults: PositionDef[];                       // key, label, line, x, y
  canRename: boolean;
  canAddRemove: boolean;
}

interface SportPlaybook {
  agePolicy(ageGroup: string): AgePolicy;
  positionModel(policy: EffectivePolicy, onFieldSize: number): PositionModel;
  strategies(policy: EffectivePolicy): StrategyDef[];  // id, label, blurb, engine adapter

}
// Effective policy = agePolicy(age) + team_playbooks.policy_overrides
// (only where overridable). Lives in src/lib/sports/<sport>/playbook.ts.
```

**Engine adapters (no rewrite):**

- AFL `suggestStartingLineup` / `suggestSwaps`: who-plays order gains the
  time floor and keep-on priority; the flat chip bonus becomes *home >
  also-plays rank > line preference*, scaled by strategy; *never* is a hard
  filter; like-for-like when the rule is on. Zoned ages keep today's
  behaviour plus `rotateLines`.
- Netball `suggestNetballLineup`: strategy chooses the scoring tiers —
  *By thirds* = today's tiers; *Position by position* = distinct-bib
  coverage; *Position cycle* = deterministic shift (no scoring needed);
  *Partners* = within-third swap; *Set positions* = home bib first. A real
  `isAllowed` is built from *never* rules.
- RL `suggestLeagueLineup` / `suggestLeagueSubs`: line from player roles
  instead of chip a/b; unbroken periods read from effective policy (fixes
  the ignored toggle); vest strategy chooses wearers.
- Every adapter returns its top reason per move for the Why chip.

### 7.10 Data model sketch

```sql
create table public.team_playbooks (
  team_id          uuid primary key references public.teams(id) on delete cascade,
  strategy         text,                        -- validated in code against the sport's strategies
  policy_overrides jsonb not null default '{}', -- {zonesEnforced?: bool, minGameTimePct?: int, ...}
  rules            jsonb not null default '[]', -- [{id, kind, params, strength, enabled}]
  updated_by       uuid references public.profiles(id) on delete set null,
  updated_at       timestamptz not null default now()
);

-- Only for sports/ages whose PositionModel.kind = 'custom' (AFL open ages).
create table public.team_positions (
  id            uuid primary key default gen_random_uuid(),
  team_id       uuid not null references public.teams(id) on delete cascade,
  label         text not null check (char_length(label) between 1 and 4),
  name          text,
  line          text not null,
  sort          smallint not null,
  on_field_size smallint,
  archived_at   timestamptz
);

-- position_key = team_positions.id (AFL), a fixed bib ('GS'…'GK'), or an
-- RL catalogue key ('FB','HK',…) — one table for all three sports.
create table public.player_position_prefs (
  id           uuid primary key default gen_random_uuid(),
  player_id    uuid not null references public.players(id) on delete cascade,
  position_key text,
  line         text,
  kind         text not null check (kind in ('home','also','never','keep_on')),
  rank         smallint,
  check (position_key is not null or line is not null or kind = 'keep_on')
);
create unique index player_position_prefs_uniq
  on public.player_position_prefs (player_id, kind, coalesce(position_key, line, ''));

alter table public.games add column playbook_snapshot jsonb;  -- effective policy + strategy at kickoff
```

**Lineup shape:** AFL `Lineup` gains optional `slots` (position → player);
zone arrays stay and are derived from slots. Netball `GenericLineup`
already keys by bib. RL `LeagueLineup` gains optional `slots` for named
positions; forwards/backs arrays stay.

**Migration:** `enforce_unbroken_periods`, `allow_mid_quarter_subs` and
`track_zone_time` move into `policy_overrides` / `rules`; "Linked to
positions" chips become line-level `also` prefs; custom split/group chips
become keep apart / together rules. Old columns stay read-only for one
release, then drop.

## 9. Decisions and open questions

**Decided by Steve (12 Oct):**

- Minimum game time defaults to **50 %**, editable in setup for leagues
  that require more.
- **Zones end at U10.** Zones for U8–U10, named positions from U11, per-team
  override kept.
- **Every netball rotation style is in scope**: By thirds, Position by
  position, Position cycle, Partners, Set positions.
- **Season balance is a core rule.** Rotations aim to even out each
  player's time in each position across the season, as a coach preference
  (on by default for rotating strategies, off for Set positions).

**Still open:**

1. **Name.** "Playbook", "How we play", or "Coaching style"?
2. **League named positions.** Reading "do all the rotation styles" as a yes
   to named positions for Mod League (U10–U12). Confirm?
3. **Season boundary.** Does a season mean the stats season selector's
   season (calendar year), or should coaches be able to reset it (e.g.
   after grading)?
4. **Role names.** Is "Coach / Helper / Parent" right? Should the team code
   keep joining people as Parent?
5. **Default formations.** Do the 12/15/16/18 position sets in §7.3 match
   what coaches in your leagues actually use?
6. **Game-day availability.** OK to fold availability into the game-day
   lineup screen and keep the separate page for the night before?
7. **Parents.** Read-only Today/Games/Stats, or a separate parent view?
8. **Navigation.** Keep top tabs, or bottom tabs for the native shells?
9. **Association rules.** Any local netball or league rules (e.g. "every
   player plays at least two positions") worth shipping as presets?
