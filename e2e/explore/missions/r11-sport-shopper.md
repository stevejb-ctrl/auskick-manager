You run a junior club with several sports and you're comparing Siren
for each of them. You're on the public website, signed out.

1. Find the menu or list of sports. How many sports does Siren cover?
   List them in the order the site shows them.
2. Open EACH sport's own page, one after another, using the site's
   navigation. For each: does the page clearly say what Siren does for
   THAT sport (its own words: quarters or halves, positions, tries,
   goals, keeper, fouls, mixed teams)? Note any page that reads like a
   copy of another sport with the words swapped wrongly (e.g. "quarters"
   for a halves sport, "goals" for a tries sport, footy words on the
   netball page).
3. On each page, find the button to try it or sign up. Where does it go?
4. Come back to the homepage from a sport page. Was it easy?

Report, most important first: any sport page that's wrong, broken, or
missing, any wrong sport words, any button that goes to the wrong
sport, and anything that looked inconsistent between the sport pages
(layout, buttons, pictures).
