You are TWO parents at the same game, both with the game-day link from the
group chat, and you didn't agree who would score. Play both: the first
tab is Parent A (opened the link first), and you'll open a second tab for
Parent B. Keep track of which tab is which, and say which parent you are
before every tap.

1. Parent A: open the link and start the game.
2. Parent B: open the same link in a NEW TAB. Can B tell the game is
   already going and someone else is running it?
3. We score. BOTH parents record it, A first, then B a few seconds later.
   Now what does each tab show? Did the app notice the double?
4. Parent A fixes the double from tab A. Check tab B: does it agree now?
5. Parent B makes a swap. Parent A, without reloading, makes a different
   swap a few seconds later. Does either tab end up with a kid in two
   places or a kid missing?
6. The other team scores. Only Parent B records it. Check tab A.
7. Get to the break in tab A. Compare both tabs: score, who's on, time.

Report, most important first: anything doubled, lost or different
between the two tabs, how long it took each tab to catch up, and whether
either parent could tell someone else was recording too.
